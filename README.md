# EVOLVE Tracker - Shadowverse EVOLVE 対戦管理アプリ (PWA v1.1)

Shadowverse EVOLVE（紙のTCG）の対戦を快適にサポートする対戦管理PWA（Progressive Web App）です。

**「中央置き（縦）」と「端置き（横）」** の2つのレイアウト、および **「詳細表示」と「シンプル表示」** の2つの表示モードを自由自在に切り替えられます。

一度ブラウザで開いて「ホーム画面に追加」すれば、**PCやインターネットがなくても完全オフラインで動作**します。

---

## 主な機能と特徴

### 1. 2つのレイアウト切替 (中央置き / 端置き)
- **中央置き (縦画面・上下分割・既定)**:
  - スマートフォンを卓の中央に置き、向かい合って座るプレイヤー同士で使用。
  - **相手側エリアは180°回転表示（対面表示）**。向かい側の相手が正対した状態で確認・操作できます。
- **端置き (横画面・左右分割・新規)**:
  - スマートフォンを卓の端に置き、両プレイヤーが**同じ向き**で画面を見るときに使用。
  - 画面を横向きにし、左に自分、右に相手の情報を並列配置（相手側の回転はなし）。
  - 設定で左右の配置入れ替え（左=相手 / 右=自分）もワンタップで可能。

### 2. 2つの表示モード切替 (詳細表示 / シンプル表示)
- **詳細表示 (現行UI・既定)**:
  - 1画面に全情報（ライフ、PP±・全回復・上限±、EP±、SEP±、進化3ボタン）が集約された情報密度の高いUI。
- **シンプル表示 (すっきりUI・新規)**:
  - ボタン数を半分以下に減らし、余白を広げたミニマルデザイン。
  - **常時表示**: 「ライフ（大文字＋±1/±5）」「PP」「EP（オーブ）」「SEP（オーブ）」「進化（1ボタン）」のみ。
  - **PPタップ**: PP微調整シートが開き、±1や上限調整、全回復が可能。
  - **EP/SEPタップ**: オーブをタップするだけで直感的に増減・消費。
  - **進化ボタン (1つのみ)**: タップすると「通常進化」「EP進化 (-1EP)」「超進化 (-1SEP)」の選択シートが展開。進化後は「進化済み (1/1)」に変化。

### 3. サイコロ & コイントス機能
- 画面中央の **「サイコロ 🎲」** ボタンからいつでも展開。
- **6面ダイス**: 1個・2個・3個を選択して振ることができ、個別の目と合計値を表示。
- **コイントス**: 表（Heads）/ 裏（Tails）を判定。
- **暗号学的公平乱数**: `crypto.getRandomValues` による一様乱数（剰余バイアスなし）。
- **対面表示対応**: 中央置きレイアウト時は、相手向き（180°反転）と自分向き（正立）の2方向同時に結果を表示。
- **履歴表示**: 直近10回の結果を記録。効果音・バイブレーション連動。

### 4. 公式ルール完全準拠のリソース管理
- **リーダー体力 (Life)**:
  - 初期値 20（設定で変更可能）。`[-5]`, `[-1]`, `[+1]`, `[+5]` クイックボタン＋数値タップによる直接編集。
- **PP (プレイポイント)**:
  - ターン進行による上限増加（毎ターン+1、最大10）＆全回復。
- **EP (エボルヴポイント)**:
  - **先攻: 0** / **後攻: 3**
  - 進化コストのPPを1つ肩代わり（1回の進化につき最大1つまで）。
- **SEP (超進化ポイント)**:
  - 各プレイヤー初期値 **1**。
  - **先攻は7ターン目以降、後攻は6ターン目以降**に自動解禁。
  - 解禁ターンになると「**超進化 READY 🔥**」が発光し、超進化ボタンが有効化。
- **進化回数制限 (1ターン1回)**:
  - 進化実行で「進化済 (1/1)」になり、ターン交代時に自動リセット。
- **取り消し (Undo)**:
  - ライフ・PP・EP・SEP・ターン交代など、誤タップした操作を直前の状態へ巻き戻し可能（常時利用可能）。
- **対戦中の画面スリープ防止 (Screen Wake Lock API)** & **触覚フィードバック (Vibration API)**。
- **オートセーブ**: localStorage により、再起動後も直前の状態を自動復元。

## PCなしでスマートフォンで使う方法 (GitHub Pages 公開手順)

アプリは静的ファイル（HTML/CSS/JS）のみで構成されており、ビルド不要です。GitHub Pages に公開すれば、PCを起動していなくてもスマートフォンからいつでもアクセス・インストールできます。

### 1. GitHub にリポジトリをプッシュする
```bash
git add .
git commit -m "Release v1.1.0"
git branch -M main
# GitHubで作成したリポジトリURLを指定
git remote add origin https://github.com/<あなたのユーザー名>/<リポジトリ名>.git
git push -u origin main
```

### 2. GitHub Pages を有効にする
1. GitHub のリポジトリページを開き、**Settings** タブをクリック。
2. 左メニューの **Pages** を選択。
3. **Build and deployment** の Source で **Deploy from a branch** を選択。
4. Branch に **main**、フォルダに **/ (root)** を選択して **Save** をクリック。
5. 数分で `https://<あなたのユーザー名>.github.io/<リポジトリ名>/` にアプリが公開されます。

### 3. スマートフォン (Android Chrome) でインストールする
1. スマートフォンの **Google Chrome** で公開された URL を開きます。
2. 画面右上のメニュー（︙）を開きます。
3. **「ホーム画面に追加」**（または「アプリをインストール」）をタップします。
4. これでホーム画面に専用アイコンが配置され、以降は**PCの起動不要・電波のないオフライン環境でも完全動作**します。

## ローカルで起動する場合 (PC)

```powershell
python -m http.server 8080
```
ブラウザで `http://localhost:8080` を開きます。
PCと同一Wi-Fiに接続したスマホから `http://<PCのローカルIP>:8080` でもアクセス可能です。

## ファイル構成

```
.
├── index.html              # メイン画面 (中央/端置き・詳細/シンプル両対応)
├── manifest.webmanifest    # PWAマニフェスト (縦横両対応 orientation: any)
├── sw.js                   # Service Worker (オフライン完全キャッシュ v1.1.0)
├── css/
│   └── style.css           # スタイルシート (中央/端置き、詳細/シンプル、サイコロ)
├── js/
│   ├── app.js              # メインコントローラー、DOMバインド、レンダリング
│   ├── store.js            # 状態管理、ルールエンジン、履歴Undo、localStorage
│   ├── dice.js             # 公平乱数ダイス (1〜3個) & コイントスマネージャー
│   ├── audio.js            # Web Audio API 効果音シンセサイザー
│   └── device.js           # Screen Wake Lock & Vibration API 管理
└── icons/
    ├── icon.svg            # ベクターアイコン
    ├── icon-192.png        # PWAアイコン (192x192)
    └── icon-512.png        # PWAアイコン (512x512)
```
